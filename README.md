# Shaoun Chandra Shill – Portfolio (React + TypeScript + Vite)

```bash
npm install
npm run dev        # instant hot reload at http://localhost:5173 (also on your LAN)
npm run build      # type-check + production build into dist/
npm run preview    # serve dist/ at http://localhost:4173
npm run lighthouse # run while preview is up (needs Chrome)
```

- Content lives in `src/data/*.ts` – edit text, links and projects there.
- Deploy: push to `main` (Pages source = "GitHub Actions"), or upload the contents of `dist/`.
- `legacy/` holds your previous plain HTML/CSS/JS site, untouched.
